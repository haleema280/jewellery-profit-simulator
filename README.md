# What Would These Changes Earn You? 💖

Interactive profit calculator for jewellery brands built from real customer data (505 customers).

### The Problem
77+ age group is 34% of customers but brings under 8% of spend. 51-68 and 17-31 bring 72% of spend.

### The Solution - 3 Levers

1. **Shift marketing to best buyers** - Move 77+ ad budget to top groups
2. **Convert 22-44 savers** - High earners but low spending score (0.31 vs 0.77)
3. **Grow orders from proven buyers** - Bundles, loyalty, repeat orders

### Result with Sample Data
- **Extra yearly profit: +Rs 318,691**
- Profit today: Rs 750,000 -> With changes: Rs 1,068,691
- Profit margin: 15.0% -> 17.7%
- Extra revenue: +Rs 1,033,037

Breakdown:
- Marketing shift: +Rs 128,898
- Convert savers: +Rs 69,097
- Order growth: +Rs 120,696

### Features
- Enter your own revenue, gross margin, marketing % 
- Move sliders, results update instantly
- No Excel formulas needed
